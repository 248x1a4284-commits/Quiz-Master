# QuizMaster - Complete Android Quiz App & Web Studio

QuizMaster is an interactive quiz application with multiple categories, custom question creator, high score tracking, Open Trivia DB integration, and complete downloadable Flutter & Dart source code.

## 🌟 Interactive Preview
The app running in this environment is a full-featured, responsive implementation of QuizMaster featuring:
- **Interactive Quiz Rounds**: 5-question sessions with 4 options, automated scoring, 50:50 lifelines, timer countdown, and instant explanations.
- **6 Master Categories**: Programming, Computer Science, General Knowledge, Science, Mathematics, Technology, and Custom User Quizzes.
- **Custom Question Creator**: Add questions with reactive field validation and live preview.
- **Leaderboard & Best Scores**: Persistent records saved locally.
- **Android Phone Simulation**: Click the smartphone icon in the top header to preview the app inside a Google Pixel 8 Pro frame, or switch to the spacious responsive desktop view.
- **Sound Effects**: Synthesized audio feedback via the Web Audio API (chimes, ticks, fanfares) with mute toggle.
- **Flutter Code Exporter**: Download the complete Flutter project as a `.zip` file or explore every single Dart file directly.
